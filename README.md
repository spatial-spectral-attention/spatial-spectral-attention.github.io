# Spatial-Spectral Coupling as Attention

The [project website](https://spatial-spectral-attention.github.io/) is served from `gh-pages`. The `main` branch is reserved for the code release.

Run `python3 -m http.server 8931` from this directory and open `http://localhost:8931/` to preview the site.

The hero uses the Three.js teaser from the project talk. The viewer, pial meshes and correspondence assets are under `static/teaser/`. Each stage pauses for exploration. Select **Continue** to advance or use the chapter buttons to revisit a stage that has already started. The publication button and BibTeX point to [arXiv:2611.13870](https://arxiv.org/abs/2611.13870).

Layout inspired by Hybrid Functional Maps, TopoOR, COMPOSE and DisPOSE.
